About MathPy

A focused mathematical computing environment built around speed, predictable APIs and efficient execution.

Our goal

MathPy began as an experiment into how quickly common mathematical questions could be evaluated when the execution layer was designed specifically for the workload.


The project has since evolved into a general-purpose mathematical toolkit for Python developers who need fast answers without manually optimizing every calculation.

Designed differently

Rather than exposing every internal implementation detail, MathPy provides a deliberately small interface. The engine decides how each problem should be evaluated.


This allows future releases to improve the underlying engine while keeping existing applications compatible.

Project history

2022

Initial prototype

The first MathPy prototype was created to evaluate batches of algebraic expressions more efficiently.

2023

Symbolic engine introduced

Symbolic equation solving and expression simplification became part of the core API.

2025

The current execution architecture introduced optimized batch processing and significantly reduced function overhead.

from mathpy import solve

answer = solve( "x² - 5x + 6 = 0" )

Batch operations

MathPy can process large collections of independent expressions through the batch API.

expressions = [
   "2 + 2",
   "15 * 8",
   "sqrt(144)"
]

results = solve.batch(expressions)
